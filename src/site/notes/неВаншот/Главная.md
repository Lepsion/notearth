# Система "неВаншот"

**неВаншот** — система для проведения словесных ролевых игр, объединяющая свободное повествование, отыгрыш персонажей и игровые механики.

Система предоставляет инструменты для создания персонажей, разрешения игровых ситуаций, проведения сражений и взаимодействия с окружающим миром. Она призвана сохранить свободу действий, присущую словесным ролевым играм, дополнив её понятными и последовательными правилами.

**Главная задача системы** — простой подход с сохранением прокачки и развития персонажа.
