# Дух

***Д*ух** — это базовая характеристика персонажа, определяющая его волевые возможности: выносливость, интуицию, эмпатию и способность противостоять внешним воздействиям.

**В бою** — определяет способность переносить боль, сопротивляться пагубным воздействиям и противостоять ментальному урону.

**Вне боя** — позволяет чувствовать потоки магии и энергии, распознавать эмоциональное состояние окружающих и противостоять психологическому давлению. Помимо этого может выступать для проверки некоего предчувствия персонажа, необъяснимого, интуитивного решения.

Минимальное значение — 1.

Максимальное значение — 4.

Стартовое значение определяется способностями персонажа.

Подробнее о распределении характеристик — [[Баланс персонажа\|Баланс персонажа]].
