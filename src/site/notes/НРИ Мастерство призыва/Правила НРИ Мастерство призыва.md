# Правила НРИ Мастерство призыва

## 1. Подготовка поля
- Игровое поле собирается из **гексогональных сегментов** (количество зависит от числа игроков: базовый размер — 7×7 гексов).
- В **центральной зоне** поля (3-4 гекса в центре) в случайном порядке рассыпаются **кубики (дайсы)**, обозначающие залежи маны.  Значение на кубах и их расположение рекомендуется использовать случайное. В противном случае - расклад должен устраивать всех игроков. 
  > *Рекомендация:* количество кубов = 3 + число игроков.
  - Определяется очерёдность хода (любой жеребьёвкой). 
  - Игроки получает карточку **Искры** и призывают по 1 существу на одном из крайних гексах (по выбору). 
  - Каждый игрок получает по 5 маны.
  - Рядом с игровым полем, в доступе для каждого игрока, выкладывается колода Рынка и 5 карточек существ. 
  

## 2. Условие победы
Побеждает игрок, чьи юниты **единолично** (без наличия вражеских юнитов) **продержатся в центральной зоне поля в течение 3 полных ходов**.

Под «полным ходом» понимается:
- 1 ход самого игрока **+**
- 1 ход каждого соперника (то есть зона должна быть чистой после окончания хода последнего игрока).


## 3. Структура хода игрока
В свой ход игрок выполняет действия в следующем порядке.  
Пропускать можно любую фазу, кроме **«Обновления рынка»** (она обязательна).


### 3.1 Фаза «Портал» (получение доступа к существам)
Игрок выбирает из общего пула (рынка) существо, которое хочет получить в свой резерв.

**Процедура:**
1. Игрок объявляет о намерении открыть портал и указывает конкретную карточку.
2. **Аукцион** (перехват существа) - **любой соперник** может начать аукцион:

- Участники по очереди либо **повышают ставку на 1 маны**, либо **пасуют**.
- Аукцион завершается, когда все, кроме одного, отказались от торгов.
3. **Победитель** (или текущий игрок в случае отсутствия аукциона) забирает карточку существа себе.
4. Получивший карточку обязан оплатить **«Стоимость Портала»** или сбросить её в стопку сброса. 
- **ВСЯ мана, потраченная всеми участниками торгов**, безвозвратно отправляется в банк.

> ⚠️ *Важно:* Игрок, изъявивший об открытии портала, не обязан вступать в аукцион. Если он пасует, он просто теряет право на эту карту. При этом Стоимость Портала он не оплачивает. 


### 3.2 Фаза «Призыв» (вывод существ на поле)
Игрок может призвать существ только из своего резерва (за которые уже оплачена стоимость портала).

**Ограничения:**
- За один призыв активируется **только 1 группа существ** (одна карточка).
- На каждой карточке указана **максимальная численность** (обозначается количеством кубиков на ней).
- Игрок может призвать от 1 до N существ из этой группы.

**Стоимость:**
- За каждое призванное существо игрок платит **«Стоимость Призыва»** (указана на карте).
- Если стоимость равна 0 — призыв бесплатный. Это может случиться в результате некоторых событий. Однако отрицательным призыв стать не может. 

**Кубики и резервы:**
- Один кубик **всегда остаётся на карточке** даже после призыва остальных — это «шаблон» или «ядро» существа, чтобы помнить о наличии группы.
- **При гибели:** кубик погибшего существа отправляется в **общий банк** и **не возвращается** на карточку. Таким образом, запас группы истощается безвозвратно.


### 3.3 Фаза «Ход группы» (активные действия)
Игрок выбирает **одну группу** своих юнитов на поле, среди тех, что ещё не ходили в этом цикле и выполняет следующие действия строго по порядку:


#### 3.3.1 Передвижение
- Все существа группы перемещаются на расстояние, равное их характеристике **«Скорость»**.
- Перемещение происходит **поочерёдно** (по одному юниту).
- Существа **не могут занимать клетку**, уже занятую другим существом (своим или вражеским).
- Существа могут проходить сквозь союзников, не мешая их движению.


#### 3.3.2 Атака
**Выбор целей:**
- Каждый юнит в группе может атаковать **отдельную цель**.
- **ИЛИ** юниты могут сконцентрироваться на **одной общей цели** — в этом случае их показатели атаки суммируются.
- По умолчанию, существа могут атаковать лишь существ на соседнем гексе. 


**Бросок и расчёт урона:**
1. Атакующий бросает **кубик D6** и прибавляет свою характеристику **«Атака»**.
2. Защищающийся бросает **кубик D6** и прибавляет свою характеристику **«Защита»**.
3. Сравниваются итоговые значения:
   - Если выпавшее значение (с бонусом атаки) атакующего **больше** защищающегося → урон равен **разнице** (превосходству) значений.
   - Если выпавшее значение (с бонусом защиты) защищающегося **больше или равно** → атака считается **«заблокированной»**, урон не наносится.

> 📌 *Примечание:* у всех существ по умолчанию **6 жизней**.


**В случае гибели:**
1. Кубик поверженного существа отправляется в **банк**. 
2. Карточка поверженного существа отправляется в колоду сброса (если не сказано иное). 


#### 3.3.3 Захват маны
- Все существа выбранной группы, которые **закончили ход** на гексах с кубиками маны, **немедленно забирают** эти кубики в свой резерв.
- Каждый куб даёт игроку **ману** в значении на кубике.


#### 3.3.4 Конец хода
Для обозначения, что данная группа не может больше ходить до наступления нового цикла, карточка существа поворачивается на бок. 


### 3.4 Фаза «Обновление рынка» (обязательная)
Игрок должен:
- **Убрать 1 юнита** с текущего рынка (его карточка отправляется в стопку сброса).
- **Выложить 1 нового юнита** из колоды рынка на освободившееся место.

> ⚠️ Если игрок не хочет менять состав — он **обязан сбросить верхнюю карту колоды** 
- **Если колода рынка закончилась** - перетасовать колоду сброса. Теперь она считается колодой рынка. 
- **Если все существа всех игроков совершили ход в текущем цикле - начинается новый цикл** (все существа активируются). 


## 4. Важные термины (глоссарий)

| Термин         | Описание                                                                           |
| -------------- | ---------------------------------------------------------------------------------- |
| **Портал**     | Действие по получению карточки существа в резерв. Оплачивается стоимостью портала. |
| **Призыв**     | Действие по выводу существ из резерва на поле. Оплачивается стоимостью призыва.    |
| **Банк**       | Общий резерв маны, куда уходят средства с аукционов и кубики погибших существ.     |
| **Рынок**      | Общая зона с карточками существ, доступными для открытия портала.                  |
| **Резерв**     | Личные карточки существа, за которые уплачен портал (их можно призывать).          |
| **Ход группы** | Активация одной группы существ для движения, атаки и сбора маны.                   |
| **Цикл**       | Череда ходов игроков от активации первого существа, до активации последнего.       |

## 5. Пример краткого хода

1. **Игрок А** хочет получит **Огненного элементаля**, чей портал равен 2. 
2. **Игрок Б** начинает аукцион, тратит 1 ману. 
3. **Игрок А** пасует → **Б** забирает элементаля, доплачивает 2 маны за портал. Все 3 маны уходят в банк.
4. **Игрок А** призывает скелета (стоимость призыва 1), ставит кубик на поле.
5. В фазе хода группы двигает скелета на 2 гекса, атакует врага (бросок 5+1=6 против 3+0=3 → наносит 3 урона), забирает куб маны с гекса.
6. Обновляет рынок — сбрасывает одну карту, вытягивает новую.
